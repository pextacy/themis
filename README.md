# THEMIS

**Evidence, not opinions, for every contribution.**

THEMIS is an evidence-first triage system for open-source maintainers facing a flood of
low-quality pull requests, issues and security reports. It does not try to detect who or
what wrote a submission. It checks whether the submission's claims are true.

Status: pre-implementation baseline. This commit holds the project plan only, with no
application code. See [`docs/PRD.md`](docs/PRD.md) and [`docs/PLAN.md`](docs/PLAN.md).

Built for the Mozilla MozFest "Developers Wilding: Online" hackathon.
